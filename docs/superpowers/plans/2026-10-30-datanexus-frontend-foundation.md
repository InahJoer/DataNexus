# DataNexus Frontend Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the existing NestJS project into `/backend` and add a separate `/frontend` Next.js prototype for access, workspace entry, and a B2B SaaS dashboard.

**Architecture:** Keep `/backend` and `/frontend` as sibling applications with their own package manifests. The frontend uses Next.js App Router, TypeScript, custom CSS, inline SVG for the small chart, and sample data; it does not call the API in this slice.

**Tech Stack:** NestJS 12, Prisma, SQLite, Next.js, React, TypeScript, CSS.

**Spec:** `docs/superpowers/specs/2026-10-30-datanexus-frontend-foundation-design.md`

## Global Constraints

- The current backend is NestJS 12, TypeScript, Prisma, and SQLite for local development.
- The existing architecture document already identifies Next.js as the web client.
- Current users have one `workspaceId`; login returns that ID, and there is no workspace-list endpoint.
- Keep Git metadata and developer-specific folders at the repository root. Generated `node_modules` and `dist` output are not source files to relocate.
- Preserve environment values without printing them; the backend `.env` belongs in `/backend` for local API execution.
- Keep commands simple and avoid unnecessary builds or broad validation runs.
- The access, workspace, and dashboard screens use sample data and do not call the backend.

## Review Focus

- Backend package commands still work from the new directory; perform one backend build after moving the project.
- `/` sends the user to `/login`, and the demo login continues to `/workspaces`.
- The workspace action opens `/dashboard`; the dashboard identifies the selected sample workspace.
- Dashboard navigation and content remain readable at desktop and narrow viewport widths.
- The root README describes where each application lives and how to start it.
